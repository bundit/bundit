# Hey I'm Bundit 🌊
*(bun-dit — like *pundit*, with a 🅱️)*

You can tell I’m a TypeScript developer because I use emojis 🙈

I’ve worked all over from polished frontends to core backend services, infrastructure, analytics, architecture, and engineering strategy. These days, I’m both interested in **what we should build, why** and **how we build it well**.

I get deep into technicals, but my impact naturally wanders beyond code. I’ve led teams and projects, set technical direction, shaped product decisions, and helped engineers grow into bigger roles.

## 🥳 Work I enjoy

- Greenfield systems where its not obvious what "good" is yet
- Full-stack problems that span more than one layer or stack
- Scaling things that worked great right up until people actually started using them
- Products that makes life more fun
- Developer experience and tooling that gives back time to engineers 

Most of my classic-programming mileage is in **TypeScript, React, Next.js, NestJS, Java, and SQL**, but I’m not a zealot to one language, framework, or layer of the stack. The fun part is figuring out what the problem actually needs.
